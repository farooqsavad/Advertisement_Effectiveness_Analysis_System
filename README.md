# Advertisement Effectiveness Analysis

This project provides a comprehensive analysis of advertisement effectiveness using multiple datasets. It includes both a Jupyter Notebook for data analysis and a professional web-based dashboard for visualization.

## Project Components

1. **Jupyter Notebook (`Advertisement_Effectiveness_Analysis.ipynb`)**
   - Data exploration and preprocessing
   - ROI and conversion rate analysis
   - Customer engagement metrics
   - Demographic analysis
   - Channel performance comparison
   - Advertising success prediction system
   - Optimization recommendations

2. **Web Dashboard**
   - Interactive visualizations
   - Professional UI with animations and transitions
   - Mobile-responsive design
   - Dark/light theme toggle
   - Prediction tool for estimating advertising success

## Datasets Used

The analysis is based on four datasets:
- `Social_Media_Advertising.csv`
- `marketing_campaign_dataset.csv`
- `Advertising_Data.csv`
- `advertising.csv`

## Features

- **Comprehensive Analysis**: Detailed examination of advertising effectiveness across multiple dimensions
- **Interactive Visualizations**: Dynamic charts and graphs for better data understanding
- **Prediction System**: AI-powered model to forecast advertising success
- **Optimization Recommendations**: Data-driven suggestions for improving advertising ROI
- **Professional UI**: Modern, responsive interface with animations and transitions

## Getting Started

1. Open the Jupyter Notebook to explore the data analysis:
   ```
   jupyter notebook Advertisement_Effectiveness_Analysis.ipynb
   ```

2. View the web dashboard by opening `index.html` in a web browser

## Technologies Used

- **Data Analysis**: Python, Pandas, NumPy, Scikit-learn
- **Visualization**: Matplotlib, Seaborn, Plotly
- **Web Frontend**: HTML5, CSS3, JavaScript
- **Charts**: Chart.js
- **Animations**: AOS (Animate On Scroll)
